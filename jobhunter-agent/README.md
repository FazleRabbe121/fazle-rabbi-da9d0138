# 🤖 JobHunter — হোটেল/রেস্টুরেন্ট জব খোঁজা ও আবেদন পাঠানোর এজেন্ট

২৪ ঘণ্টা সার্ভারে চলে, ফোনের **Telegram** থেকে কন্ট্রোল হয়।

**কাজের ধারা:** শহর দিন → হোটেল/রেস্টুরেন্ট খুঁজবে → ওয়েবসাইটের Careers পেজ পড়বে → জব আসল কিনা বিচার করবে → ইমেইল বের করে ভেরিফাই করবে → **Sponsor Score** দেবে → আপনার জন্য কাস্টম ইমেইল ড্রাফট করবে → আপনি ✅ দিলে নিরাপদ গ্যাপে একটা একটা করে পাঠাবে → রিপ্লাই/বাউন্স ধরবে → ৭ দিন পর ফলো-আপ ড্রাফট করবে।

## ডুপ্লিকেট ও আটকে যাওয়া কেন আর হবে না
- প্রতিটা মেইল ডাটাবেসের কিউতে থাকে: `draft → approved → sending → sent`
- একই ঠিকানায় দুটো আবেদন **ডাটাবেস নিজেই** ঢুকতে দেয় না
- পাঠানোর মাঝখানে সংযোগ কেটে গেলে এজেন্ট নিজে আবার পাঠায় **না** (গেছে কিনা অনিশ্চিত); `/review`-এ আপনি Gmail Sent দেখে "গেছে/আবার" বেছে নেন
- দৈনিক সীমা + ধীরে বাড়ানো (warm-up) + ৪৫–১২০ সেকেন্ড র‍্যান্ডম গ্যাপ + কাজের সময় (সকাল ৮–সন্ধ্যা ৬)

## সেটআপ (প্রথমবার)

### ১. দরকারি জিনিস
- Python 3.11+ (কম্পিউটারে টেস্টের জন্য) এবং পরে একটা সার্ভার (VPS ~৫$/মাস) যাতে ২৪ ঘণ্টা চলে
- **নতুন একটি আলাদা Gmail** (প্রধান Gmail নয়, কারণ ভুল হলে ব্লক হওয়ার ঝুঁকি থাকে)

### ২. Telegram বট
1. Telegram-এ **@BotFather** → `/newbot` → টোকেন কপি করুন → `.env`-এ `TELEGRAM_BOT_TOKEN`
2. `TELEGRAM_CHAT_ID` এখন খালি রাখুন (নিচে ধাপ ৬ দেখুন)

### ৩. Gmail App Password
1. Gmail অ্যাকাউন্টে **2-Step Verification** চালু করুন
2. Google Account → Security → **App passwords** → নতুন পাসওয়ার্ড (১৬ অক্ষর) তৈরি করুন
3. Gmail → Settings → Forwarding and POP/IMAP → **IMAP চালু** করুন (রিপ্লাই পড়ার জন্য)
4. `.env`-এ `GMAIL_ADDRESS` ও `GMAIL_APP_PASSWORD` বসান (সাধারণ পাসওয়ার্ড নয়!)

### ৪. Gemini key
https://aistudio.google.com/apikey থেকে key নিন → `GEMINI_API_KEY`। না দিলেও এজেন্ট চলে (নিয়মভিত্তিক মোডে), তবে AI থাকলে জব বোঝা ও ইমেইল লেখা অনেক ভালো।

### ৫. ফাইল প্রস্তুত
```bash
cp .env.example .env              # তারপর .env এডিট করুন
cp profile.example.json profile.json   # তারপর নিজের সত্য তথ্য দিন
# আপনার CV (PDF) রাখুন: cv/CV.pdf
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py check               # সব সংযোগ পরীক্ষা করে ✅/❌ দেখায়
```
⚠️ `profile.json`-এ **শুধু সত্য তথ্য** লিখুন। AI শুধু ওখানকার তথ্য ব্যবহার করে। work_authorization লাইনে নিজের অবস্থা সৎভাবে লিখুন।

### ৬. চালু করুন
```bash
python run.py
```
Telegram-এ বটকে `/start` দিন → সে আপনার **Chat ID** বলবে → `.env`-এ `TELEGRAM_CHAT_ID=...` বসিয়ে এজেন্ট রিস্টার্ট করুন। (শুধু ওই Chat ID-র কমান্ড কাজ করে, অন্য কেউ কন্ট্রোল করতে পারবে না।)

## ২৪ ঘণ্টা চালানো (সার্ভারে)
**Docker:** `docker compose up -d --build` (লগ: `docker compose logs -f`)
**অথবা systemd:** `jobhunter.service` ফাইলের পথ/ইউজার ঠিক করে নির্দেশনা অনুযায়ী চালু করুন।
ডাটা থাকে `data/jobhunter.db` — এটাই এজেন্টের মেমোরি, ব্যাকআপ রাখুন।

## ফোনের কমান্ড
| কমান্ড | কাজ |
|---|---|
| `/find Zagreb HR` | শহরের হোটেল খোঁজা (`all` যোগ করলে রেস্টুরেন্ট/বারসহ) |
| `/drafts` | ড্রাফট দেখে ✅ পাঠান / ⏭ বাদ / 👁 পুরো দেখুন |
| `/approve_all` | সব ড্রাফট কিউতে (ধীরে ধীরে যাবে) |
| `/status`, `/top`, `/replies` | অবস্থা, সেরা কোম্পানি, রিপ্লাই |
| `/mode approve\|auto` | অনুমোদন মোড / অটো মোড |
| `/spontaneous on\|off` | জব পোস্ট নেই, কিন্তু স্কোর ভালো — এমন কোম্পানিতেও আবেদন |
| `/cap 30` | দৈনিক সীমা |
| `/review` | "গেছে কিনা নিশ্চিত না" মেইল |
| `/pause`, `/resume` | সব বন্ধ/চালু |
| `/suppress x@y.com` | এই ঠিকানায় আর কখনো নয় (`@y.com` = পুরো ডোমেইন) |
| `/export` | সব কোম্পানি + ইমেইল CSV হিসেবে |

## প্রথম সপ্তাহের পরামর্শ
1. `MODE=approve` রাখুন। প্রতিটা ড্রাফট নিজে পড়ে ✅ দিন
2. ১–২টি শহর দিয়ে শুরু (যেমন `/find Zagreb HR`, `/find Valletta MT`)
3. প্রথম দিনে ১০টি, প্রতিদিন +৫ করে বাড়বে (`WARMUP_*`)
4. ২–৩ সপ্তাহে ড্রাফটের মান ভালো লাগলে তবেই `/mode auto`

## Sponsor Score কীভাবে কাজ করে
০–১০০ স্কোর, প্রতিটা পয়েন্টের কারণ `/export`-এর `score_reasons` বা ডাটাবেসে দেখা যায়: জব পোস্ট আছে কি না, ভিসা/work permit/non-EU উল্লেখ, থাকার ব্যবস্থা, ইমেইল ডোমেইন ওয়েবসাইটের সাথে মেলে কি না, ইমেইল কাজ করে কি না, টাকা চাওয়ার মতো স্ক্যাম লক্ষণ (-৪০)।
**এটা অনুমান, স্পনসরশিপের গ্যারান্টি নয়।** আসল সিদ্ধান্ত কোম্পানি ও সংশ্লিষ্ট দেশের ইমিগ্রেশন নিয়মের ওপর। কোনো কোম্পানি বা এজেন্টকে **কখনো টাকা দেবেন না**। `data.py`-র `HIGH_DEMAND` তালিকা আপনার নিজের অভিজ্ঞতায় বদলান।

## দায়িত্বশীল ব্যবহার (জরুরি)
- এজেন্ট `robots.txt` মেনে চলে, প্রতি সাইটে ২ সেকেন্ড গ্যাপ দেয়
- প্রতিটা মেইল আলাদা ও ব্যক্তিগত। BCC-তে গণমেইল নয়
- প্রতিটা মেইলের নিচে opt-out লাইন থাকে। কেউ "stop" লিখলে বা বাউন্স হলে ঠিকানা স্থায়ীভাবে সাপ্রেশন লিস্টে যায়
- ইউরোপে ব্যক্তিগত ইমেইল ঠিকানায় অযাচিত মেইল নিয়ে GDPR/স্থানীয় আইন আছে। তাই `hr@`/`info@` ধরনের কোম্পানির ঠিকানা অগ্রাধিকার পায়। সন্দেহ হলে `/suppress` ব্যবহার করুন
- Gmail-এর দৈনিক সীমা ছোঁয়ার আগেই থামুন: নতুন অ্যাকাউন্টে ২০–৪০/দিন নিরাপদ

```
run.py                 শুরু করার ফাইল (run / check / export)

cv/CV.pdf              প্রতিটা আবেদনে সংযুক্ত হয়
jobhunter/
  sources.py           কোম্পানি খোঁজা (OpenStreetMap ফ্রি + Google Places ঐচ্ছিক)
  crawler.py           ওয়েবসাইট/Careers পেজ পড়া, ইমেইল সংগ্রহ
  analyzer.py          জব আসল কিনা (নিয়ম + Gemini)
  scoring.py           Sponsor Score + ইমেইল যাচাই (MX)
  drafts.py            ইমেইল ড্রাফট (Gemini + নিরাপদ টেমপ্লেট)
  mailer.py            নির্ভরযোগ্য কিউ ও পাঠানো
  inbox.py             রিপ্লাই/বাউন্স/stop ধরা (IMAP)
  commands.py          Telegram কমান্ড ও বাটন
  agent.py             সব লুপ একসাথে চালায়
tests/                 python -m unittest discover -s tests -v   (২৫টি টেস্ট)
```

## সমস্যা হলে
- `python run.py check` প্রথমে চালান, কোনটা ❌ দেখুন
- `data/agent.log` ফাইলে বিস্তারিত লগ
- Gmail লগইন ব্যর্থ → App Password ঠিক আছে কিনা এবং 2-Step চালু কিনা দেখুন
- কোনো শহরে কিছু পাওয়া না গেলে → স্থানীয়/ইংরেজি বানান বদলান বা `GOOGLE_PLACES_API_KEY` যোগ করুন
- JavaScript-ভারী সাইট পড়তে না পারলে → `pip install playwright && playwright install chromium` এবং `USE_PLAYWRIGHT=1`

ড্রাফট এডিট কমান্ড, দেশভিত্তিক CV অনুবাদ, Telegram থেকে CV আপলোড, ওয়েব ড্যাশবোর্ড, সরকারি স্পনসর-লিস্ট ইমপোর্ট।
